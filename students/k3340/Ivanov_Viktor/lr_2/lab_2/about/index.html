    о проекте¶

    цель лабораторной работы¶

    данная лабораторная работа направлена на изучение веб-разработки с использованием Django framework. в процессе выполнения заданий студент получает практический опыт создания полнофункциональных веб-приложений с использованием современных технологий и паттернов разработки.

    изучаемые темы¶

    Django framework модели данных и ORM - работа с базами данных через объектно-реляционное отображение, представления - функциональные и классовые (Function-based и Class-based Views), шаблоны - Django Template Language для создания динамических страниц, формы - ModelForm для валидации и обработки данных, админ-панель - встроенная система администрирования, миграции - управление изменениями схемы базы данных.

    работа с моделями создание моделей данных - определение структуры данных, связи между моделями - ForeignKey, OneToOne, ManyToMany, расширение AbstractUser - кастомизация модели пользователя, валидация данных - проверка корректности данных на уровне модели, методы моделей - добавление бизнес-логики в модели.

    представления и формы Function-based Views - простые функции для обработки запросов, Class-based Views - переиспользуемые классы представлений (ListView, DetailView, CreateView, UpdateView, DeleteView), ModelForm - автоматическое создание форм из моделей, обработка форм - валидация, сохранение, обработка ошибок, контекст шаблонов - передача данных в шаблоны.

    аутентификация и авторизация система пользователей - регистрация, вход, выход, расширение User модели - добавление дополнительных полей, разграничение доступа - проверка прав пользователей, хеширование паролей - безопасное хранение паролей.

    технологический стек¶

    Python 3.13 - основной язык программирования (все проекты), Django 5.2.7 - веб-framework (модели, представления, шаблоны), SQLite 3 - встроенная база данных (разработка и тестирование), Django ORM - объектно-реляционное отображение (запросы к БД), Django Forms - работа с формами (валидация, обработка), Django Admin - админ-панель (управление данными), Django Templates - шаблонизатор (динамические страницы), HTML5/CSS3 - фронтенд (интерфейс пользователя).

    статистика проектов¶

    количество Django проектов: 3, общее количество файлов: 100+, строк кода: 3500+, моделей данных: 8+, представлений: 25+, форм: 10+, шаблонов: 25+, URL маршрутов: 50+.

    образовательные цели¶

    теоретические знания понимание архитектуры MTV (Model-Template-View), знание принципов работы Django ORM, понимание паттернов Class-based Views, знание системы миграций Django, понимание принципов аутентификации и авторизации.

    практические навыки создание веб-приложений на Django, проектирование моделей данных, работа с формами и валидацией, настройка админ-панели, создание пользовательских интерфейсов, отладка и тестирование приложений.

    описание проектов¶

    проект 1: автовладельцы (практические задания 2.1-2.2) система управления данными об автовладельцах, автомобилях, владении и водительских удостоверениях. реализованы базовые CRUD операции, функциональные и классовые представления, формы для создания и редактирования данных, админ-панель с настройкой отображения. проект демонстрирует основы работы с Django: создание моделей, настройка связей между ними, работа с представлениями и шаблонами.

    проект 2: табло авиарейсов (основная лабораторная работа) полнофункциональное веб-приложение для управления информацией об авиарейсах. реализована система регистрации пользователей с расширенной моделью (AbstractUser), система бронирования мест на рейсах с проверкой доступности, система отзывов о рейсах с рейтингами, админ-панель для подтверждения бронирований, красивый адаптивный интерфейс. проект демонстрирует продвинутые возможности Django: расширение модели пользователя, сложные связи между моделями, аннотации и агрегация в запросах, работа с аутентификацией.

    проект 3: расширение модели пользователя (практическое задание №3) расширение проекта "автовладельцы" с добавлением кастомной модели пользователя. добавлены новые поля: номер паспорта, домашний адрес, национальность. полная интеграция с существующей системой, обновление всех представлений и шаблонов, настройка AUTH_USER_MODEL. проект демонстрирует миграцию существующего проекта на кастомную модель пользователя, что является важным навыком для реальных проектов.

    развитие проектов¶

    возможные улучшения PostgreSQL/MySQL - использование производственных СУБД, REST API - создание API для мобильных приложений, аутентификация через соцсети - OAuth2 интеграция, файловые загрузки - работа с изображениями и документами, кэширование - оптимизация производительности, асинхронность - использование Django Channels для WebSocket, тестирование - написание unit и integration тестов.

    дополнительные возможности развертывание - Docker, Kubernetes, CI/CD, мониторинг - Sentry, логирование, производительность, безопасность - HTTPS, CSRF, XSS защита, интернационализация - поддержка нескольких языков, responsive design - адаптация под все устройства.

    выполненные задания¶

    практические задания 2.1 создание проекта Django, создание моделей данных и миграций, настройка админ-панели, создание контроллеров и HTML-шаблонов, работа с адресацией (URL routing).

    практические задания 2.2 доработка модели данных (связь многие-ко-многим), функциональные представления для владельцев, классовые представления для автомобилей (CRUD), формы для владельцев (функциональные), формы для автомобилей (классовые).

    практическое задание №3 расширение пользовательской модели (AbstractUser), создание кастомной модели User с новыми полями, настройка AUTH_USER_MODEL в settings.py, обновление всех связанных моделей, создание кастомной админ-панели, реализация интерфейса регистрации с расширенными полями.

    основная лабораторная работа регистрация новых пользователей с расширенными полями, просмотр и резервирование мест на рейсах, редактирование и удаление своих резервирований, регистрация пассажиров администратором, таблица пассажиров рейса, написание отзывов к рейсам с рейтингами.
